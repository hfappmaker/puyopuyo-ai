# 仕様書 目次

## プロジェクト概要

ぷよぷよの盤面シミュレーションと連鎖エンジンを備えたAI学習ツール。
AIが算出した「次の一手」を見て、連鎖の組み方を学習できる。

## 用語定義

| 用語 | 定義 |
|------|------|
| 軸ぷよ | ぷよ組の回転中心となるぷよ |
| 衛星ぷよ | 軸ぷよの周りを回転するぷよ |
| ツモ | 落下してくる2個1組のぷよ |
| 連鎖 | 同色4個以上の消去が連続して発生する反応 |
| 致死行 | 3列目の行12を超える位置。ここに到達するとゲームオーバー |
| ウォールキック | 壁際での回転時に自動的に位置を補正する仕組み |
| ゴースト | ハードドロップ先を示す半透明の表示 |
