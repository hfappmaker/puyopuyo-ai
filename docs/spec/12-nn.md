# ニューラルネットワーク仕様

## 概要

盤面の評価をヒューリスティックではなく CNN（畳み込みニューラルネットワーク）で行うための、モデル定義と入力エンコーディングを提供する。機械学習フレームワークには [Burn](https://burn.dev/) を使用する。

## クレート構成

```
crates/puyo-nn/
├── src/
│   ├── lib.rs          # モジュール公開
│   ├── encoding.rs     # 盤面 → テンソル変換
│   └── model.rs        # CNN モデル定義
└── Cargo.toml
```

## 依存関係

| クレート | 用途 |
|---------|------|
| `burn` | ニューラルネットワークフレームワーク |
| `puyo-core` | `Board`, `PuyoColor`, 定数類, `flood_fill` |

## 盤面エンコーディング (`encoding`)

盤面を8チャンネルの浮動小数点テンソルに変換する。チャンネル0〜4はone-hot形式、チャンネル5〜7は構造的特徴量。

### 定数

| 名前 | 値 | 説明 |
|------|-----|------|
| `NUM_CHANNELS` | 8 | one-hot 5ch + 構造的特徴量 3ch |
| `TENSOR_SIZE` | 672 | `NUM_CHANNELS × ROWS × COLS` = 8 × 14 × 6 |

### テンソルレイアウト

```
[channel][row][col] = [8][14][6]
```

| チャンネル | 内容 | 正規化 |
|-----------|------|--------|
| 0 | Empty (one-hot) | 0 or 1 |
| 1 | Red (one-hot) | 0 or 1 |
| 2 | Green (one-hot) | 0 or 1 |
| 3 | Blue (one-hot) | 0 or 1 |
| 4 | Yellow (one-hot) | 0 or 1 |
| 5 | Column Heights | `column_height(col) / ROWS` (0〜1) |
| 6 | Adjacent Empty | 非空セルの隣接Empty数 / 4.0 (0〜1) |
| 7 | Group Size | 非空セルの連結グループサイズ / 4.0 (4+で>1.0) |

#### チャンネル0〜4（one-hot）

各セル `(col, row)` の色に対応するチャンネルが 1.0、それ以外は 0.0 となる。

#### チャンネル5（Column Heights）

各列の高さ（`column_height(col)`）を `ROWS` で割って正規化。列内の全セルが同じ値を持つ。

#### チャンネル6（Adjacent Empty）

非空セルについて、上下左右4方向の隣接セルのうちEmptyであるものの数を4で割って正規化。空セルは0.0。

#### チャンネル7（Group Size）

`flood_fill` を使って同色の連結グループを走査し、各セルにグループサイズ / 4.0 を設定。`flood_fill` は `VISIBLE_ROWS` で制限されるため、隠し行（row 12-13）は自然に0.0となる。空セルは0.0。

### インデックス計算

```
index = channel * ROWS * COLS + row * COLS + col
```

### API

```rust
pub fn board_to_tensor_data(board: &Board) -> [f32; TENSOR_SIZE]
```

### テンソル変換

`board_to_tensor_data` で得られた `[f32; 672]` の1次元配列は、NN に入力する際に4次元テンソルに reshape する。

```
[672] → reshape → [batch, 8, 14, 6]
                   │      │   │   └── COLS
                   │      │   └────── ROWS
                   │      └────────── NUM_CHANNELS
                   └───────────────── バッチサイズ
```

## CNN 価値ネットワーク (`model`)

### アーキテクチャ: `PuyoValueNet`

盤面を入力として、スカラー評価値を出力する回帰モデル。Residual接続（残差接続）を採用し、勾配消失を抑えつつ表現力を確保している。

#### `ResidualBlock`

同一チャンネル数を維持する残差ブロック。入力をショートカット接続で出力に加算する。

```
x → Conv(3×3) → ReLU → Conv(3×3) → (+) → ReLU → y
|                                     ↑
└─────────────────────────────────────┘
```

#### 全体構成

| レイヤー | 種類 | 入力 | 出力 | カーネル | パディング | 備考 |
|---------|------|------|------|---------|-----------|------|
| stem | Conv2d | 8ch | 32ch | 3×3 | Same | 入力チャンネル射影 |
| relu | ReLU | - | - | - | - | |
| res_block ×2 | ResidualBlock | 32ch | 32ch | 3×3 | Same | 残差接続付き |
| head_conv | Conv2d | 32ch | 64ch | 1×1 | - | チャンネル拡張 |
| relu | ReLU | - | - | - | - | |
| pool | AdaptiveAvgPool2d | 64ch | 64ch | → 4×3 | - | |
| flatten | Reshape | 64×4×3 | 768 | - | - | |
| linear1 | Linear | 768 | 128 | - | - | |
| relu | ReLU | - | - | - | - | |
| linear2 | Linear | 128 | 1 | - | - | |

#### 定数

| 名前 | 値 | 説明 |
|------|-----|------|
| `RESIDUAL_CHANNELS` | 32 | Residualブロック内のチャンネル数 |
| `NUM_RESIDUAL_BLOCKS` | 2 | Residualブロックの個数 |
| `HEAD_CHANNELS` | 64 | ヘッド部のチャンネル数 |
| `POOL_H` / `POOL_W` | 4 / 3 | AdaptiveAvgPool2d の出力サイズ |
| `HIDDEN_SIZE` | 128 | 全結合層の隠れ層サイズ |

### 入出力

- **入力形状**: `[batch, 8, 14, 6]`（one-hot + 構造的特徴量エンコード済み盤面）
- **出力形状**: `[batch, 1]`（スカラー評価値）

### 初期化

```rust
let config = PuyoValueNetConfig::new();
let model = config.init::<B>(&device);
```

## モデルの保存・読み込み

| 用途 | レコーダー | 形式 |
|------|-----------|------|
| 教師あり学習後の保存（`train`） | `CompactRecorder` | Burn 標準バイナリ形式 |
| WASM 経由の読み込み（`load_nn_model`） | `BinBytesRecorder` | バイト列から直接ロード |
| 自己対戦中のターゲットネットワーク更新 | 一時ファイルを介した保存→再ロード | `CompactRecorder` |

`BinBytesRecorder` はバイト列から直接モデルを復元するため、ファイルシステムが存在しないブラウザ環境（WASM）でも動作する。

## 互換性

チャンネル数の変更（5→8）により、既存の訓練データ（`data/training_data.bin`）と学習済みモデル（`artifacts/puyo_model.bin`）は互換性がない。再生成・再学習が必要。
