# システム構成

## 概要

Rust でゲームロジックとAIを実装し、WASM 経由でブラウザ上に表示する。

## 構成

| レイヤー | 役割 |
|----------|------|
| puyo-core | 盤面・ぷよ組・連鎖・スコア・ゲーム進行・乱数 |
| puyo-ai | 盤面評価と最善手探索 |
| puyo-wasm | Rust とブラウザの橋渡し |
| web | 画面表示・ゲームループ |

## データフロー

1. ゲームループが AI に最善手を問い合わせる
2. AI が全配置を評価し、最善手を返す
3. 最善手を盤面に適用する
4. 画面を描画・更新する
