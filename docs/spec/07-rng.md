# 乱数生成仕様

## 概要

決定論的な乱数生成器を使用する。同じシードからは常に同じツモ列が生成されるため、ゲームの再現性が保証される。

## アルゴリズム

xorshift64 を使用する。

```rust
pub struct Rng {
    state: u64,
}
```

```
x ^= x << 13
x ^= x >> 7
x ^= x << 17
```

## シードの扱い

- シード0は1に置き換える（xorshift の全0状態を回避）
- ゲーム初期化時に `Date.now()` の値をシードとして使用する

## 用途

- `next_range(n)`: 0 以上 n 未満の整数を生成
- ぷよ組の色決定に使用（`next_range(4) + 1` で色番号 1〜4 を生成）
- ゲーム初期化時に3回呼び出し（現在のぷよ組・ネクスト・ネクネクの軸と衛星で計6回の `next_range`）
