# フロントエンド仕様

## 概要

ブラウザ上で盤面とAIの次の一手を表示する TypeScript + Vite フロントエンド。

## 画面構成

- **盤面**: 6列×12行のグリッドにぷよを Canvas で表示（セルサイズ: 40px）
- **ネクスト表示**: 次のぷよ組を表示（80×80px）
- **ネクネク表示**: 次の次のぷよ組を縮小表示（60×60px）
- **サイドバー**: 固定幅160pxでNEXT・スコア・AI評価・配置一覧等のパネルを表示
- **スコア表示**: 現在のスコア・最大連鎖数・設置済みぷよ数
- **ゴースト表示**: ハードドロップ先を半透明（25%）で表示

## ぷよの描画

| 色 | メインカラー | ハイライト |
|----|-------------|-----------|
| 赤 | `#e94560` | `#ff7b93` |
| 緑 | `#4ade80` | `#86efac` |
| 青 | `#60a5fa` | `#93c5fd` |
| 黄 | `#fbbf24` | `#fcd34d` |

ぷよは円形で描画し、放射状グラデーションのハイライトと白い目（瞳付き）を持つ。

## キー操作

| キー | アクション | InputAction |
|------|-----------|-------------|
| ← | 左移動 | `move_left` |
| → | 右移動 | `move_right` |
| ↑ | 時計回り回転 | `rotate` |
| ↓ | ソフトドロップ（着地位置ならハードドロップ＋設置） | `soft_drop` |
| Space | AIプレビュー / 設置確定（2段階操作） | `ai_move` |
| R | リスタート | `restart` |

## 操作モデル

ぷよは自動で落下しない。プレイヤーが↓キーを押すたびに1マスずつ下降する。
着地位置（これ以上下がれない位置）で↓を押すとハードドロップが実行され、ピースが設置されて連鎖処理が行われる。

## AIプレビュー操作

1. Spaceキー1回目: AIが最善手を計算し、着地位置をゴーストプレビューで表示する（プレビュー状態）
2. プレビュー中は他のキー操作（移動・回転・ドロップ）を受け付けない（RestartとSpaceのみ有効）
3. Spaceキー2回目: `apply_placement_direct` でピースを直接配置する

AI配置は `apply_placement_direct(col, ori)` により直接適用される。以前の rotate→move 操作シミュレーション方式は、回転ブロックや移動失敗時に配置がずれる問題があったため廃止された。

## 配置一覧パネル

サイドバーに「配置一覧」パネルがあり、現在のピースで可能な全配置をボタンで一覧表示する。

- ピースが着地するたびに `game.enumerate_placements()` を呼び出し、リストを更新
- 各ボタンは `col + orientation名` で表示（例: `2N`, `3E`）
  - orientation名: 0=N（上）、1=E（右）、2=S（下）、3=W（左）
- ボタンをホバーまたはクリックすると、盤面上にその配置の着地位置をゴーストプレビュー描画（半透明＋白枠線で区別）
- クリックでアクティブ状態を維持、マウス離脱時もプレビューが残る
- ゲームオーバー時やリスタート時にリストはクリアされる

## AI評価パネル

AIプレビュー実行時に、サイドバーの「AI評価」パネルに評価スコアと最善手を表示する。

- `ai_best_move()` の戻り値から `f64` スコアを `DataView.getFloat64()` で抽出
- スコアは小数点第1位まで表示
- 最善手は `col + orientation名`（例: `2N`）で表示
- ピース着地時・リスタート時にパネルを非表示にする

## ゲームオーバー

- ゲームオーバー時はオーバーレイで最終スコアと最大連鎖数を表示
- R キーでリスタート可能（新しいシードで再初期化）

## モジュール構成

| ファイル | 役割 |
|---------|------|
| `main.ts` | エントリポイント。WASM ロード・各モジュール初期化・AI モード切り替え |
| `game-loop.ts` | ゲームループ管理。入力処理・AI操作・リスタート |
| `renderer.ts` | Canvas 描画。盤面・現在ピース・ゴースト・ネクスト・ネクネク |
| `input.ts` | キーボード入力のマッピング |
| `ui.ts` | スコア・ゲームオーバーオーバーレイの DOM 操作 |
| `wasm.ts` | WASM モジュールのロードとキャッシュ（シングルトン） |
| `constants.ts` | 定数定義（サイズ・色・オフセット） |
| `types.ts` | WasmGame インターフェース定義 |
| `model-loader.ts` | NN モデルの fetch・パース・ロード |

## NN モデルの読み込み

`model-loader.ts` は以下の URL からリソースを並列 fetch し、`game.load_nn_model()` に渡す。

| リソース | URL |
|---------|-----|
| モデル本体 | `/models/puyo_model_selfplay.bin` |
| 正規化パラメータ | `/models/norm_params.txt` |

`norm_params.txt` は `mean` と `std_dev` を改行区切りで2行記載したテキストファイル。
fetch に失敗した場合や、リソースが存在しない場合は `console.warn` を出力してヒューリスティックにフォールバックする。
