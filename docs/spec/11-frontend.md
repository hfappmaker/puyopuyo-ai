# フロントエンド仕様

## 概要

ブラウザ上で盤面とAIの次の一手を表示する TypeScript + Vite フロントエンド。

## 画面構成

- **盤面**: 6列×12行のグリッドにぷよを Canvas で表示（セルサイズ: 40px）
- **ネクスト表示**: 次のぷよ組を表示（80×80px）
- **ネクネク表示**: 次の次のぷよ組を縮小表示（60×60px）
- **スコア表示**: 現在のスコア・最大連鎖数・設置済みぷよ数
- **ゴースト表示**: ハードドロップ先を半透明（25%）で表示

## ぷよの描画

| 色 | メインカラー | ハイライト |
|----|-------------|-----------|
| 赤 | `#e94560` | `#ff7b93` |
| 緑 | `#4ade80` | `#86efac` |
| 青 | `#60a5fa` | `#93c5fd` |
| 黄 | `#fbbf24` | `#fcd34d` |

ぷよは円形で描画し、放射状グラデーションのハイライトと白い目（瞳付き）を持つ。

## キー操作

| キー | アクション | InputAction |
|------|-----------|-------------|
| ← | 左移動 | `move_left` |
| → | 右移動 | `move_right` |
| ↑ | 時計回り回転 | `rotate` |
| ↓ | ソフトドロップ（着地位置ならハードドロップ＋設置） | `soft_drop` |
| Space | AIプレビュー / 設置確定（2段階操作） | `ai_move` |
| R | リスタート | `restart` |

## 操作モデル

ぷよは自動で落下しない。プレイヤーが↓キーを押すたびに1マスずつ下降する。
着地位置（これ以上下がれない位置）で↓を押すとハードドロップが実行され、ピースが設置されて連鎖処理が行われる。

## AIプレビュー操作

1. Spaceキー1回目: AIが最善手を計算し、ピースをその位置に移動・回転する（プレビュー状態）
2. プレビュー中は他のキー操作（移動・回転・ドロップ）を受け付けない（RestartとSpaceのみ有効）
3. Spaceキー2回目: プレビュー位置でハードドロップし設置する

AIプレビュー時の移動は `rotateTo` と `moveTo` によって最短経路で実行される。

## ゲームオーバー

- ゲームオーバー時はオーバーレイで最終スコアと最大連鎖数を表示
- R キーでリスタート可能（新しいシードで再初期化）

## モジュール構成

| ファイル | 役割 |
|---------|------|
| `main.ts` | エントリポイント。WASM ロード・各モジュール初期化 |
| `game-loop.ts` | ゲームループ管理。入力処理・AI操作・リスタート |
| `renderer.ts` | Canvas 描画。盤面・現在ピース・ゴースト・ネクスト・ネクネク |
| `input.ts` | キーボード入力のマッピング |
| `ui.ts` | スコア・ゲームオーバーオーバーレイの DOM 操作 |
| `wasm.ts` | WASM モジュールのロードとキャッシュ |
| `constants.ts` | 定数定義（サイズ・色・オフセット） |
| `types.ts` | WasmGame インターフェース定義 |
