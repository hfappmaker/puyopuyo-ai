# フロントエンド仕様

## 概要

ブラウザ上で盤面とAIの次の一手を表示するフロントエンド。

## 画面構成

- **盤面**: 6列×12行のグリッドにぷよを表示
- **ネクスト表示**: 次のぷよ組を表示
- **スコア表示**: 現在のスコア・最大連鎖数・設置済みぷよ数

## ぷよの色

| 色 | 表示色 |
|----|--------|
| 赤 | `#e94560` |
| 緑 | `#4ade80` |
| 青 | `#60a5fa` |
| 黄 | `#fbbf24` |

## キー操作

| キー | アクション |
|------|-----------|
| ← / → | 横移動 |
| ↑ | 回転 |
| ↓ | 1マス下に移動（着地位置なら設置） |
| Space | AIの最善手をプレビュー（2回目で設置） |
| R | リスタート |

## 操作モデル

ぷよは自動で落下しない。プレイヤーが↓キーを押すたびに1マスずつ下降する。
着地位置（これ以上下がれない位置）で↓を押すとピースが設置され、連鎖処理が実行される。

## ゲームオーバー

- ゲームオーバー時はオーバーレイで最終スコアと最大連鎖数を表示
- R キーでリスタート可能
