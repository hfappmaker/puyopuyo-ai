# フロントエンド仕様

## 概要

ブラウザ上で盤面とAIの次の一手を表示するフロントエンド。

## 画面構成

- **盤面**: 6列×12行のグリッドにぷよを表示
- **ネクスト表示**: 次のぷよ組を表示
- **スコア表示**: 現在のスコア・最大連鎖数・設置済みぷよ数
- **AI状態表示**: 自動再生の ON/OFF

## ぷよの色

| 色 | 表示色 |
|----|--------|
| 赤 | `#e94560` |
| 緑 | `#4ade80` |
| 青 | `#60a5fa` |
| 黄 | `#fbbf24` |

## キー操作

| キー | アクション |
|------|-----------|
| Space / → | 次の一手（AIが最善手を計算し、落下アニメーション付きで配置） |
| A | 自動再生の ON/OFF 切り替え |
| R | リスタート |

## 落下アニメーション

「次の一手」実行時の動作:

1. AIが最善手（列・向き）を計算
2. ピースを目標の列・向きに即座に移動（回転→横移動）
3. `requestAnimationFrame` ベースのアニメーションでピースが落下
4. 着地すると連鎖処理が走り、次のピースが出現して静止状態に戻る

### 定数

| 定数 | 値 | 説明 |
|------|-----|------|
| `DROP_SPEED` | 3.0 cells/sec | 落下速度 |
| `AUTO_PLAY_DELAY` | 300ms | 自動再生時、着地後に次の手を開始するまでの待機時間 |

### 状態マシン

```
IDLE → (次の一手) → DROPPING → (着地) → IDLE
                                        ↓ (自動再生時)
                                   300ms待機 → 次の一手
```

- **IDLE**: 静止状態。rAFループ停止。入力受付可。
- **DROPPING**: rAFループ稼働中。`tick(gravity)` で毎フレーム落下。入力ロック（リスタート除く）。

### 重力計算

デルタタイム方式で一定速度を保証:

```
gravity = DROP_SPEED × (deltaMs / 1000)
```

deltaMs は前フレームからの経過時間（最大100msでキャップ、タブ非表示時のジャンプ防止）。

### 着地判定

`game.tick(gravity)` 呼び出し前後で `total_pieces` を比較。増加していればピースが着地して次のピースが出現したことを意味する。GameOver 時は `total_pieces` が増加しないため `phase === GAME_OVER` で補完。

## 自動再生モード

- A キーで ON/OFF を切り替え
- ON にすると即座に最初の手を実行（IDLEの場合）
- 各手に落下アニメーションが付く
- 着地後 `AUTO_PLAY_DELAY`（300ms）待ってから次の手を自動実行
- OFF にすると進行中のアニメーションは完走するが、次の手は発生しない

## ゲームオーバー

- ゲームオーバー時はオーバーレイで最終スコアと最大連鎖数を表示
- R キーでリスタート可能
