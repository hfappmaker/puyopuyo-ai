# AI 探索仕様

## 概要

現在のぷよ組と次のぷよ組の2手先まで読み、最も評価の高い配置を「次の一手」として提示する。

## 探索の流れ

1. 現在のぷよ組の全配置パターンを列挙する
2. 各配置に対して、次のぷよ組の全配置パターンも列挙する
3. 2手目まで置いた結果の盤面を評価関数で採点する
4. 最も高い評価を得た1手目の配置を「次の一手」として返す

## 配置パターン

- 4方向（上・右・下・左）× 各列 = 最大22パターン
- 軸ぷよと衛星ぷよが同色の場合は重複を排除し、最大11パターン

## フォールバック

2手先読みで有効な結果がない場合（全てゲームオーバーになる場合など）は、1手先読みに切り替える。
