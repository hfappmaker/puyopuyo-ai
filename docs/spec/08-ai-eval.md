# AI 評価関数仕様

## 概要

盤面の「良さ」をスコアとして数値化する。AIが配置を比較・選択するための判断基準。

## 評価項目

| 評価項目 | 良い盤面の条件 |
|---------|--------------|
| 連鎖スコア | 現時点で発生する連鎖のスコアが高い |
| 連鎖長 | 長い連鎖が発生する |
| 高さ | 列が高くなりすぎていない |
| 高さの均一さ | 列の高さが揃っている |
| 連結度 | 同色のぷよが隣接している |
| 潜在連鎖 | あと少しで消える連結グループが多い |
| 中央寄り | 中央列にぷよが集まっている |
| ゲームオーバー回避 | 致死状態にならない |

ゲームオーバーになる配置は極端に低い評価を受け、回避される。
