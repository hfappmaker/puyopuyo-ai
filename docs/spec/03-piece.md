# ぷよ組・ツモ仕様

## ぷよ組の構成

2個1組のぷよ（軸ぷよ + 衛星ぷよ）で構成される。

## 方向

衛星ぷよは軸ぷよに対して4方向に配置できる。

| 方向 | 衛星の位置 |
|------|-----------|
| North | 軸の上 |
| East | 軸の右 |
| South | 軸の下 |
| West | 軸の左 |

## 出現位置

- 3列目（列2）の上端に出現
- 初期方向は North（衛星が上）

## 配置

AIの探索結果は「どの列に、どの方向で置くか」で表現される。

## ウォールキック

壁際で回転できない場合、自動的に反対方向に1マスずれて回転を成立させる。
