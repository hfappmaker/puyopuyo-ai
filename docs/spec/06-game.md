# ゲーム進行仕様

## ゲームフェーズ

| フェーズ | 説明 |
|---------|------|
| Falling | ぷよ組が落下中 |
| Resolving | 設置後の連鎖を処理中 |
| GameOver | ゲーム終了 |

## 進行の流れ

1. ぷよ組が出現する
2. AI が最善手を計算し、配置を提示する
3. ぷよが設置される
4. 連鎖があれば処理し、スコアを加算する
5. ゲームオーバーでなければ次のぷよ組が出現する（1に戻る）

## ゲームの状態

- 盤面
- 現在のぷよ組
- 次のぷよ組（ネクスト）
- スコア
- 最大連鎖数
- 設置済みぷよ組数

## ツモの生成

4色（赤・緑・青・黄）から軸ぷよと衛星ぷよをそれぞれランダムに選択する。
