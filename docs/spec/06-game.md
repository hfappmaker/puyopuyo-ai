# ゲーム進行仕様

## ゲームフェーズ

| フェーズ | 値 | 説明 |
|---------|----|----|
| Falling | 0 | プレイヤーがぷよ組を操作中 |
| Resolving | 1 | 設置後の連鎖を処理中 |
| GameOver | 2 | ゲーム終了 |

`GamePhase::as_u8()` メソッドでフェーズを整数に変換できる。WASM境界で使用。

### tick メソッド

`tick(gravity)` は落下中のぷよ組に重力を適用する。着地判定はヘルパー `landing_row_for` に委譲し、借用の衝突を避けている（clone不要）。

## ゲームの状態 (GameState)

| フィールド | 型 | 説明 |
|-----------|----|----|
| `board` | `Board` | 盤面 |
| `current_piece` | `Option<FallingPiece>` | 現在操作中のぷよ組 |
| `next_piece` | `Piece` | 次のぷよ組（ネクスト） |
| `next_next_piece` | `Piece` | 次の次のぷよ組（ネクネク） |
| `score` | `u32` | 累計スコア |
| `max_chain` | `u32` | 最大連鎖数 |
| `phase` | `GamePhase` | 現在のフェーズ |
| `rng` | `Rng` | 乱数生成器 |
| `total_pieces` | `u32` | 設置済みぷよ組数 |

## 進行の流れ

1. ゲーム初期化時に3つのぷよ組を生成（現在・ネクスト・ネクネク）
2. 現在のぷよ組が `SPAWN_COL`（列1）・`VISIBLE_ROWS as f32`（6.0）・North方向で出現する
3. プレイヤーが操作（移動・回転・ドロップ）またはAIが最善手を提示する
4. ぷよが設置される（ハードドロップまたはソフトドロップで着地後に設置）
5. 連鎖処理 (`resolve_chains`) を実行し、スコアを加算する
6. `max_chain` を更新する
7. ゲームオーバー判定を行う
8. ゲームオーバーでなければネクストを現在に、ネクネクをネクストに繰り上げ、新しいネクネクを生成する

## ピースの設置

方向に応じた設置順序:

| 方向 | 設置順序 |
|------|---------|
| North | 軸を先に落とし（下）、衛星を上に積む。ただし衛星の着地先セルが既に占有されている場合（row 13 孤立ぷよ）は衛星の配置をスキップする |
| South | 衛星を先に落とし（下）、軸を上に積む |
| East / West | 軸と衛星をそれぞれの列に独立して落とす |

## 操作

| 操作 | メソッド | 説明 |
|------|---------|------|
| 左移動 | `move_left()` | Falling フェーズのみ有効 |
| 右移動 | `move_right()` | Falling フェーズのみ有効 |
| 時計回り回転 | `rotate_cw()` | Falling フェーズのみ有効 |
| 反時計回り回転 | `rotate_ccw()` | Falling フェーズのみ有効 |
| ハードドロップ | `hard_drop()` | 即座に設置し連鎖処理を実行 |
| ソフトドロップ | `soft_drop()` | 1マス下降。着地位置なら `false` を返す |
| 重力適用 | `tick(gravity)` | 1フレーム分の重力を適用。着地したら `hard_drop` を呼び `Option<ChainResult>` を返す |
| AI配置適用 | `apply_placement()` | 指定した配置で設置し連鎖処理を実行 |
| ピース設置 | `place_piece(piece, placement)` | 方向に応じた順序でぷよを盤面に配置する（連鎖処理・次ピース生成なし） |
| ピース設置のみ | `place_piece_only(placement)` | 現在のぷよ組を設置のみ（連鎖解決・次ピース生成なし）。訓練ループ用 |
| 連鎖後の確定 | `finalize_after_chains(total_score, max_chain)` | スコア・連鎖数更新、ゲームオーバー判定、次ピース生成 |

## ツモの生成

`NUM_COLORS` 色（`board.rs` からインポート。NUM_COLORS=3 なら赤・緑・青）から軸ぷよと衛星ぷよをそれぞれ独立にランダム選択する。`PuyoColor::all_colors()` で取得したアクティブな色リストを使用する。

## レンダリング情報取得

| メソッド | 戻り値 | 説明 |
|---------|--------|------|
| `get_current_piece_info()` | `Option<(u8, u8, u8, f32, u8)>` | 現在のぷよ組の情報（軸色, 衛星色, 列, 行, 方向）を返す |
| `get_next_piece_info()` | `(u8, u8)` | ネクストの（軸色, 衛星色）を返す |
| `get_next_next_piece_info()` | `(u8, u8)` | ネクネクの（軸色, 衛星色）を返す |

## リスタート

`restart(seed)` で新しいシードでゲームを完全にリセットする。
