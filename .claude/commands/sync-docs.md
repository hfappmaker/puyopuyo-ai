現在のコードベースを正として、`docs/spec/` 配下のドキュメントとの乖離を検出し修正してください。

## 手順

1. CLAUDE.md の「ドキュメント更新ルール」のマッピングテーブルを参照し、全ソースファイルと対応するドキュメントの組み合わせを確認する
2. 各ソースファイルの以下の情報を収集する:
   - 公開定数（名前・値）
   - 公開構造体・enum（フィールド名・型）
   - 公開関数のシグネチャ
   - 重要なコメント・ドキュメントコメント
3. 対応する `docs/spec/` のドキュメントと突き合わせ、以下の乖離を検出する:
   - 定数値の不一致（例: チャンネル数、テンソルサイズ、配列長）
   - 構造体フィールドの追加・削除・名前変更
   - 関数シグネチャの変更
   - API一覧の欠落（新規追加されたが文書化されていないメソッド）
   - 動作説明の不正確さ（例: `>` vs `>=`、サイズの誤記）
4. 検出した乖離を全て修正する
5. ソースコード内のドキュメントコメント（`///` や `//`）がコードと矛盾している場合はそれも修正する
6. CLAUDE.md の記述もコードベースと整合していることを確認し、乖離があれば修正する

## 注意事項

- ソースコードが正（truth）。ドキュメントをコードに合わせる（コードをドキュメントに合わせない）
- 修正対象は `docs/spec/`、`CLAUDE.md`、ソースコード内コメントのみ。ソースコードの実装は変更しない
- 変更があった場合は、何をどう修正したかの一覧を最後に報告する
